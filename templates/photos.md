# Photo checklist

Appearance is a threshold good, not a linear one. All of the value is in
clearing the floor and none of it is above, so this table is a checklist and not
a project.

The costume rule: every entry must be justifiable without naming the group you
hope it appeals to. If the justification needs the group, the entry is a
costume.

`shotcard.py` parses this table by its heading and its column names. Rename
either and it errors rather than printing a card with blank fields.
